OpenSpec task lists commonly omit the documentation gate task (AGENTS.md behavioral rule). When reviewing specs that introduce new MCP tools or modify user-facing command behavior, check that tasks.md includes an explicit documentation impact assessment step covering AGENTS.md updates, CHANGELOG.md entries, and website docs issue filing. The verification section (typically the last phase) is the natural location for this task.
