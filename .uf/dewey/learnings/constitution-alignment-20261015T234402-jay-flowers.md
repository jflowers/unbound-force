Unbound Force OpenSpec proposals created after the org constitution 1.4.0 amendment (2026-10-14, adding Principle V Security by Default and Principle VI Deterministic Execution, for six total) must assess all six principles in their Constitution Alignment section. Proposals modeled on pre-amendment peers (e.g., finale-token-reduction, created 2026-10-12) inherit a four-principle I-IV assessment template — a stale-template trap. The constitution's Governance Compliance Review rule requires the planning-phase check to verify alignment with ALL active principles. The reliable pattern is a dedicated verification task enumerating I-VI (see unleash-direct-review-dispatch task 7.1) plus a proposal Constitution Alignment section covering all six, including V and VI for any change touching file writes, permissions, input validation, or command-to-tool extraction.
