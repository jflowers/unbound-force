Determinism adjudication for guidance prose (Constitution Principle VI / DE-001): command text that routes agents to an existing executable tool satisfies the mandate when it states constraints (prohibitions, fallback paths) over judgment work like research direction — e.g., the sibling-references paragraph points at acquire_sibling_evidence, which internally performs the config discovery, verification, and pinning. It violates DE-001 when it re-implements a fixed procedure (existence check plus deterministic branch plus enumeration) that a single tool invocation already encapsulates. Test: if the surrounding work is judgment (what to research, what is relevant), the prose is a constraint layer; if the prose itself is the procedure with the same output every time, extract it to the tool.
