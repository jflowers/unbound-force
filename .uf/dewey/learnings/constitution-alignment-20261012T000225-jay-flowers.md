When reviewing OpenSpec proposals for constitution alignment, always verify the assessment covers ALL current org constitution principles. The org constitution was amended to add Principle V (Security by Default) in v1.3.0, but some proposal templates and agent habits still assess only four principles (I-IV). The Compliance Review gate requires verification against 'all active org principles' — missing one is a governance gap finding.
