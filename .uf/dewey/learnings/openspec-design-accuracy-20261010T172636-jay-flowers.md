When OpenSpec design decisions describe a specific implementation mechanism and the implementation chooses a different mechanism, the design document AND all referencing artifacts (tasks.md, proposal.md) should be updated to reflect the actual implementation choice. The Guard persona flags stale design decisions as MEDIUM intent drift when the implementation diverges from the documented approach, even when the implementation is superior.
