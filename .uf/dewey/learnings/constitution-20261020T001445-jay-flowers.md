After the Unbound Force org constitution 1.4.0 amendment (2026-10-14), every new OpenSpec proposal's Constitution Alignment section must assess all six principles: I Autonomous Collaboration, II Composability First, III Observable Quality, IV Testability, V Security by Default, VI Deterministic Execution. Proposals assessing only I-IV fail the Compliance Review gate's requirement to verify "all active org principles" and deviate from peer changes created post-amendment. Principle VI is often the easiest PASS to claim for emitter/validator unification work — sharing one derivation function is exactly Deterministic Execution — so omitting it also forfeits the change's strongest alignment citation.
