Adding a new workflow tier to a command that renders prescribed status displays and announcements as prose compounds Deterministic Execution (DE-003) debt invisibly: the new tier's display is new instruction in a MUST-rule domain even when it mirrors the adjacent pre-existing prose, so the opportunistic-migration clause never fires — every addition individually "follows the local pattern". Where the command family already has formatter-tool precedent (format_unleash_exit / format_unleash_demo for /uf.unleash), route new prescribed output formats through a formatter tool or record the deferral explicitly in the change artifacts; otherwise announce/display prose accretes one tier at a time.
