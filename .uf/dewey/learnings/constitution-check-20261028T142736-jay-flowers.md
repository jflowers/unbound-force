Constitution checks go stale by version. The Unbound Force org constitution v1.4.0 (amended 2026-10-14) carries six principles: I Autonomous Collaboration, II Composability First, III Observable Quality, IV Testability, V Security by Default, VI Deterministic Execution. Proposals whose Constitution Alignment section enumerates only I–IV were written from a pre-V/VI template and fail the Compliance Review gate, which MUST verify alignment with all active principles at each planning phase (observed in the derive-per-run-timeout spec review, 2026-10-28: both omitted assessments would have passed, but the gate record was incomplete). Enumerate principles from the current constitution file at authoring time, never from memory or a prior proposal's section.
