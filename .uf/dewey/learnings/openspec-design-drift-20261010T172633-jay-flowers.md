When a design decision evolves during implementation (e.g., D2 changed from BunShell template literals to Bun.spawn argument arrays), ALL OpenSpec artifacts should be updated: design.md, tasks.md, AND proposal.md. Only updating design.md leaves other artifacts stale and triggers repeat review findings across iterations.
